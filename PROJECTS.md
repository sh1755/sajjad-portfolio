# Research & Open-Source Project Catalogue

**Robotics · Embodied AI · Human–Robot Interaction · Large Language Models · Applied Machine Learning**

This catalogue groups the public GitHub repositories of [sh1755](https://github.com/sh1755) by research area. Projects can belong to more than one area; the categories are intended to make navigation easier rather than impose a strict taxonomy.

For the personal research website, visit [sajjad-portfolio](https://sajjad-portfolio-flax.vercel.app/).
